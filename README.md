# لوطی — بازار امن خرید و فروش اکانت بازی

لوطی (Looti؛ کسی که قولش قول است و امانت را نگه می‌دارد، و Loot به زبان گیمرها) یک بازار آگهی‌محور شبیه دیوار است، مخصوص اکانت بازی‌هایی مثل فورتنایت، رینبو سیکس، کانتر، والورانت، پابجی و…
تفاوت اصلی: **هیچ معامله‌ای مستقیم انجام نمی‌شود.** پول خریدار تا پایان کار نزد لوطی امانت می‌ماند و یک واسط، اکانت را قبل از تحویل بررسی می‌کند.

- Django 5.2 · PostgreSQL 16 · Tailwind CSS v4 · HTMX 2 · Alpine.js 3
- رابط کاملاً راست‌به‌چپ و موبایل‌محور، با تاریخ شمسی و ارقام فارسی

## راه‌اندازی

پیش‌نیاز: Python 3.12+، Node 18+، Docker (برای پستگرس).

```bash
docker compose up -d
```

```bash
cp .env.example .env
```

یک کلید رمزنگاری بساز و جلوی `CREDENTIALS_KEY` در `.env` بگذار:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

```bash
pip install -r requirements.txt
```

```bash
npm install
```

```bash
npm run build
```

```bash
python manage.py migrate
```

```bash
python manage.py seed --demo
```

```bash
python manage.py runserver 8010
```

سایت: http://localhost:8010 — پنل ادمین جنگو: `/admin/` (ورود با حساب واسط؛ نام کاربری و رمز در `ADMIN_LOGIN` / `ADMIN_PASSWORD` در `apps/core/management/commands/seed.py`)

> هنگام توسعه CSS می‌توانی به‌جای `build` از `npm run watch` استفاده کنی.

### داده نمایشی

`seed` فقط بازی‌ها را می‌سازد؛ `seed --demo` کاربر، آگهی، سفارش در همه مراحل، نظر، گفتگو و گزارش هم می‌سازد (`--reset` داده نمایشی قبلی را پاک می‌کند).

| نقش | شماره |
|---|---|
| واسط (پنل `/panel/`) | `09120000000` |
| خریدار (سفارش در همه مراحل امانت) | `09122220001` |
| فروشنده | `09121110001` |

حساب واسط مدیر کل (superuser) است. شناسه و رمز ورودش در `apps/core/management/commands/seed.py` (ثابت‌های `ADMIN_LOGIN` و `ADMIN_PASSWORD`) آمده؛ در سرور واقعی حتماً عوضش کن.

ورود با کد پیامکی است. وقتی `OTP_DEBUG=True` باشد، کد روی صفحه تأیید نشان داده می‌شود و دکمه «پر کن» آن را وارد می‌کند. در محیط واقعی باید یک سرویس پیامک در `apps/accounts` وصل شود و `OTP_DEBUG=False` شود.

### کار زمان‌بندی‌شده

سفارش‌هایی که مهلت بررسی خریدار (۷۲ ساعت) تمام شده، خودکار تکمیل می‌شوند. این کار هنگام باز شدن صفحه‌ها هم انجام می‌شود، ولی در سرور یک cron هر ۱۵ دقیقه بگذار:

```bash
python manage.py escrow_tick
```

### انتشار

`DEBUG=False`، یک `SECRET_KEY` تازه و `ALLOWED_HOSTS` درست در `.env`، سپس `npm run build` و `python manage.py collectstatic`. فایل‌های استاتیک با WhiteNoise و نام هش‌دار سرو می‌شوند.

## معامله امانی، قدم‌به‌قدم

1. **پرداخت امن** — خریدار مبلغ + کارمزد را از کیف پول یا درگاه می‌پردازد. آگهی «در حال معامله» می‌شود.
2. **تحویل به واسط** — فروشنده تا ۲۴ ساعت اطلاعات ورود را می‌فرستد. اطلاعات با Fernet رمزنگاری و ذخیره می‌شود.
3. **بررسی واسط** — واسط وارد اکانت می‌شود و ادعاهای آگهی (رنک، اسکین، ایمیل، مالک اول…) را تطبیق می‌دهد؛ یا تأیید می‌کند یا به فروشنده برمی‌گرداند.
4. **بررسی خریدار** — خریدار ۷۲ ساعت فرصت دارد رمزها را عوض کند و تأیید کند یا «مشکلی هست» بزند.
5. **تسویه** — پول به کیف پول فروشنده می‌رود. در صورت داوری، واسط با دلیل مکتوب به نفع یکی رأی می‌دهد (بازگشت وجه یا آزادسازی).

کارمزد: ۵٪ (حداقل ۳۰ هزار، حداکثر ۲ میلیون تومان) — در `config/settings.py` قابل تغییر است.

## امکانات

- **آگهی هوشمند برای هر بازی** — فرم آگهی بر اساس بازی عوض می‌شود (رنک، تعداد اسکین، سطح، ریجن…) و همین ویژگی‌ها در فیلتر جستجو هم هستند.
- **نشان سلامت اکانت** — مالک اول، دسترسی کامل ایمیل، بدون سابقه بن، تأیید دومرحله‌ای و اسکرین‌شات واقعی، روی کارت و صفحه آگهی.
- **امتیاز اعتماد فروشنده** — بر اساس فروش‌ها و خریدهای موفق، میانگین امتیاز، داوری‌های باخته و عمر حساب.
- **پیشنهاد قیمت** — خریدار پیشنهاد می‌دهد، فروشنده قبول یا رد می‌کند و خرید با همان قیمت انجام می‌شود.
- **لندینگ فقط بار اول** — بازدید اول `/` صفحه معرفی را نشان می‌دهد (کوکی `gm_seen`)؛ دفعه‌های بعد و کاربر واردشده مستقیم به همه آگهی‌ها می‌روند. صفحه معرفی همیشه از `/welcome/` (لینک «معرفی لوطی» در فوتر) در دسترس است.
- **نمایش تک‌ستونه یا چندستونه** — کنار مرتب‌سازی آگهی‌ها؛ انتخاب کاربر در مرورگر می‌ماند.
- **مقایسه آگهی‌ها** — تا چند آگهی کنار هم با نوار مقایسه شناور.
- **هشدار جستجو** — جستجو را ذخیره کن تا آگهی تازه‌ی مطابق را خبر بدهیم.
- **نشان‌کردن آگهی** و **نردبان** (بالا بردن آگهی).
- **محافظ گفتگو** — شماره تلفن، آیدی تلگرام و لینک‌های خارج از سایت در پیام‌ها پوشانده می‌شوند تا کسی معامله را بیرون نکشد.
- **گفتگوی سه‌نفره سفارش** — خریدار، فروشنده و واسط در صفحه سفارش.
- **کیف پول** — شارژ، برداشت فقط به شبای ثبت‌شده در حساب، تفکیک «در امانت» و «در راه».
- **اعلان‌ها** — منوی کشویی زنده با HTMX.
- **جستجوی سریع** — Ctrl+K یا دکمه ذره‌بین هدر، از هر صفحه، با پیشنهاد زنده.
- **گزارش آگهی** و **پنل واسط**: تأیید آگهی، بررسی اکانت، داوری و رسیدگی به گزارش‌ها.
- **نظر و امتیاز** بعد از هر معامله موفق، روی پروفایل فروشنده.
- ورود با کد پیامکی (برای حساب‌های موجود) یا با رمز، و شمارش‌گر ارسال دوباره.

## پنل مدیریت (`/panel/`)

پنل اختصاصی لوطی برای کارشناسان، جدا از ادمین جنگو (`/admin/`). مهمان به صفحه ورود فرستاده می‌شود و کاربر عادی صفحه ۴۰۳ می‌بیند.

| بخش | آدرس | کار |
|---|---|---|
| داشبورد | `/panel/` | صف‌های منتظر، شاخص‌های امروز، نمودار ۱۴ روز، سفارش‌های نیازمند اقدام، فعالیت اخیر |
| آمار و گزارش | `/panel/stats/?d=7\|30\|90` | حجم معامله، درآمد کارمزد، قیف سفارش، سهم بازی‌ها، فروشنده‌های برتر |
| بررسی اکانت | `/panel/verify/` | دیدن اطلاعات ورود رمزگشایی‌شده و تطبیق با آگهی؛ تأیید و تحویل یا برگشت به فروشنده |
| داوری | `/panel/disputes/` | رأی مکتوب به بازگشت وجه یا آزادسازی پول |
| تأیید آگهی | `/panel/listings/` | تأیید یا رد آگهی‌های در انتظار، با دلیل |
| گزارش‌ها | `/panel/reports/` | حذف آگهی یا رد گزارش |
| معامله‌ها | `/panel/orders/` | فیلتر وضعیت و جستجو، صفحه هر سفارش با خط زمانی، گفتگو، تراکنش‌ها و اقدام‌های واسط |
| کاربران | `/panel/users/` | فیلتر و مرتب‌سازی، پروفایل کامل، اعلان، مسدودسازی |
| همه آگهی‌ها | `/panel/ads/` | توقف، فعال‌سازی یا برگشت آگهی برای اصلاح |
| تنظیمات | `/panel/settings/` | کارمزد، مهلت‌ها، تأیید خودکار آگهی، اطلاعیه سراسری، روشن/خاموش کردن بازی‌ها |
| فعالیت کارشناسان | `/panel/activity/` | گزارش همه اقدام‌های پنل |

فقط مدیر کل (superuser): ذخیره تنظیمات، روشن/خاموش کردن بازی، اصلاح موجودی کیف پول، کارشناس کردن کاربر و هر تغییری روی حساب مدیر کل. همه اقدام‌ها در «فعالیت کارشناسان» ثبت می‌شوند.

## طراحی

- **لوگو**:
  - **نشان**: چهره‌ی لوطی فقط با دو نشانه: کلاه مخملی کج (با نوار کلاه) و سبیل از بناگوش در رفته. «سبیل گرو گذاشتن» یعنی قول لوطی ضمانت دارد؛ همان کاری که سایت با پول خریدار می‌کند. با هاور روی لوگو، لوطی کلاهش را برمی‌دارد و سبیلش تاب می‌خورد.
  - **لوگوتایپ**: «لوطی» با میخک Black. دو نقطه‌ی «ت» در این وزن یک قرص می‌شوند و سفالی رنگ می‌گیرند.
  - **فایل‌ها** در `static/img/brand/`:
    - `looti-mark.svg`: کاشی سفالی.
    - `looti-mark-mono.svg`: تک‌رنگ.
    - `favicon.svg`: فاوآیکن. `/favicon.ico` هم به همین فایل هدایت می‌شود.
  - **در قالب‌ها**:
    - نشان با `{% logo_mark "size-8" %}` درون‌خطی می‌شود و با currentColor رنگ می‌گیرد.
    - لوگوتایپ کلاس `.wordmark` دارد.
    - در حالت تیره هر دو خودشان رنگ عوض می‌کنند.
    - با هاور روی لوگو، لوطی کلاهش را برمی‌دارد و سبیلش تاب می‌خورد.

- **پالت گرم** (بدون رنگ نئون): ember آجری (اقدام و اعتماد)، saffron زعفرانی (توجه و گرما)، sage مریمی (امنیت و موفقیت)، espresso قهوه‌ای (متن)، cream و sand (پس‌زمینه‌ی آرام).
- **فونت**: **میخک** (Mikhak، مجوز SIL OFL 1.1) با هر ۹ وزن، از Thin تا Black، برای متن و تیتر (`static/fonts/`).
- **حالت تاریک**: با `data-theme` روی `<html>`. پیش‌فرض همان تنظیم سیستم است و انتخاب کاربر ذخیره می‌شود. نقش رنگ‌ها عوض نمی‌شود، فقط روشنایی‌شان: زمینه قهوه‌ای سوخته و متن کرم. کلید خورشید و ماه از Uiverse است.
- **حرکت**: ورود صفحه‌ها با View Transitions، منحنی‌های `ease-spring`/`ease-pop` و ورود پلکانی منوها. با `prefers-reduced-motion` همه حرکت‌ها خاموش می‌شوند.
- **آیکون‌ها**: فقط [Lucide](https://lucide.dev/icons/)، با بسته `lucide-static` و تگ `{% icon "name" %}`. هیچ ایموجی‌ای استفاده نشده.
- **تصویرسازی‌ها**: [unDraw](https://undraw.co/illustrations)، با رنگ پالت لوطی.
- **کاور بازی‌ها** (`static/img/games/<slug>.webp`، ۱۲۰۰×۷۵۰): هنر رسمی هر بازی از صفحه‌های رسمی ناشرها و فروشگاه‌ها (Epic/Xbox Store، Ubisoft/Steam، Valve/Steam، Riot، Activision، Krafton/Google Play، Supercell، Rockstar/Steam، EA). حق مالکیت تصاویر با همان ناشرهاست. با `Game.cover_url` خوانده می‌شود؛ برای بازی جدید کافی است فایلی هم‌نام اسلاگش آنجا بگذارید، وگرنه کارت گرادیان رنگ بازی و آیکن را نشان می‌دهد.
- **هدر**: اقتباس از [React Bits](https://reactbits.dev) «CardNav». نسخه اصل React و GSAP است و اینجا با Alpine و CSS بازنویسی شده، بدون نصب هیچ بسته‌ای. نوار ۶۰ پیکسلی با همبرگر باز می‌شود و سه کارت «بازار»، «معامله امن» و «لوطی من» را نشان می‌دهد. در دسکتاپ کارت‌ها کنار هم‌اند و در موبایل زیر هم. همین منو جای کشوی موبایل قبلی را گرفته است.
- **فوتر**: [21st.dev](https://21st.dev/community/components)، بر پایه «Large Name Footer».
- **هشدارها**: اقتباس از 21st.dev «alert-1». اصلش React با cva و shadcn است و پروژه React نیست، برای همین به تگ بلوکی جنگو تبدیل شده:
  `{% alert variant="warning" appearance="light" size="sm" title="…" close=True action_url="…" action_label="…" %}متن{% endalert %}`
  مقدارهای مجاز همان اصل است: variant یکی از `primary`، `destructive`، `success`، `info`، `warning`، `mono` یا `secondary`؛ appearance یکی از `solid`، `light`، `outline` یا `stroke`؛ size یکی از `sm`، `md` یا `lg`. رنگ‌ها به پالت گرم برگشته‌اند و آیکن‌ها لوسیدند.
- **هیرو صفحه اصلی**: یک تیتر روشن، جستجو، سه عدد واقعی معامله (کارمزد، مهلت تحویل، وقت امتحان) و پنل «بازار همین حالا» با تعداد آگهی و ارزان‌ترین قیمت هر بازی. همه روی یک صحنه‌ی تمام‌عرض (`.hero-stage`) که از زیر هدر شناور شروع می‌شود و ارتفاع صفحه را پر می‌کند؛ رنگ‌هایش از توکن‌های `--hero-*` می‌آید و با حالت روشن (کرم گرم) و تیره (شب گرم) عوض می‌شود: لوطیِ بزرگ (همان کلاه و سبیلِ نشان) زیر پنل نشسته و هر چند ثانیه کلاهش را به سلام برمی‌دارد؛ همان لحظه نور زعفرانی از زیر کلاه بالا می‌زند، سبیلش تاب می‌خورد و سکه‌ها بیرون می‌آیند؛ با موس هم نور ملایمی دنبال نشانگر می‌آید (`heroSpot`). با «کاهش حرکت» همه ثابت می‌شود.
- **جهت نوشتن خودکار**: ورودی‌های متنی و textareaها `dir="auto"` می‌گیرند (`static/js/app.js`)؛ متن فارسی از راست و متن انگلیسی از چپ نوشته می‌شود و ورودی خالی راست‌چین می‌ماند. ورودی‌هایی که ذاتاً لاتین‌اند (موبایل، ایمیل، رمز با کلاس `.ltr`) همیشه چپ‌چین‌اند.
- **صفحه ورود و ثبت‌نام**: کارت دوحالته (الگوی React Logins از frontendjoe): پنل سفالی با نشان لوطی بین دو نیمه می‌لغزد و فرم «ورود» و «ثبت‌نام» جایشان را عوض می‌کنند؛ آدرس هم بین `/account/login/` و `/account/register/` عوض می‌شود و در موبایل پنل نوار بالای کارت است. در نیمه‌ی ورود، کنترل Radio یوآی‌ورس بین «کد پیامکی» و «رمز عبور» جابه‌جا می‌کند. ثبت‌نام نام نمایشی، نام کاربری، موبایل و رمز (هر چهار اجباری) می‌گیرد، کد پیامکی می‌فرستد و حساب پس از تأیید کد ساخته می‌شود. ورود پیامکی با شماره‌ای که حساب ندارد به فرم ثبت‌نام می‌رود و شماره در آن پر می‌شود. مرحله‌ی واردکردن کد (`verify.html`) همان فرم OTP قبلی است.
- **چیدمان سیال**: صفحه‌های پهن از `.wrap` استفاده می‌کنند (تا `--wrap-max: 120rem` با فاصله‌ی کناری `--gutter: clamp(1rem, 3.5vw, 4rem)`)، هدر هم با همان لبه‌ها هم‌تراز است و اندازه‌ی پایه‌ی فونت بین ۱۶ تا ۱۸ پیکسل با عرض صفحه بزرگ می‌شود. شبکه‌ی کارت‌ها در صفحه‌های بزرگ ستون بیشتری می‌گیرد (بازی‌ها ۵، آگهی‌های تازه تا ۶)؛ صفحه‌های متنی عرض خوانا را نگه می‌دارند.
- **بخش‌های صفحه اصلی**: هر بخش یک نوار تمام‌عرض است و رنگش یکی‌درمیان بین کرم `#FAF6F0` و `--color-band` (`#F5EFE6`) عوض می‌شود. در حالت تیره این دو رنگ `#15100D` و `#1B1511` هستند. کلاس `.home-band` این کار را می‌کند و هیچ خط یا الگوی شبکه‌ای در کار نیست. هیچ جای سایت پس‌زمینه شطرنجی یا نقطه‌ای ندارد.
- **جستجو**: همه ورودی‌های جستجو یک کامپوننت Uiverse دارند (`.gsearch`): ذره‌بینی که با فوکوس باز می‌شود و دسته‌اش نشانگر متن می‌شود.
- **لودر**: میله‌های Uiverse در `components/loader.html`، برای همه حالت‌های بارگذاری.
- **دکمه‌ها، اینپوت‌ها، چک‌باکس‌ها، سوئیچ‌ها، کارت‌ها، فرم‌ها و لودرها**: [Uiverse](https://uiverse.io/elements). منبع هر کدام با نام سازنده بالای کلاسش در `static/src/input.css` یا در قالب نوشته شده، مثلاً `Prince4fff/slippery-baboon-37` برای کارت آگهی و `vinodjangid07/ordinary-stingray-51` برای فرم کد تأیید.

```
  chat/           گفتگو با محافظ اطلاعات تماس
  reviews/        نظر و امتیاز
  notifications/  اعلان‌ها
  panel/          میز کار واسط
  core/           صفحه‌های عمومی، تگ‌های قالب، seed
templates/        قالب‌ها (components/ = قطعه‌های مشترک)
static/src/       ورودی Tailwind و کامپوننت‌ها
```

منطق پولی فقط در `apps/escrow/services.py` است. هر تغییر وضعیت داخل تراکنش و با قفل ردیف انجام می‌شود.
